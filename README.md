# Music Store Analysis 🎵

## Overview
This project explores the **Music Store Database** through various SQL queries to analyze business insights and customer behavior. The analysis is divided into three difficulty levels: Easy, Moderate, and Advanced, covering topics like customer spending, genre popularity, artist performance, and more.

The SQL scripts provided address key questions to help the music store make data-driven decisions, such as identifying the best customer, the most popular music genre in each country, and cities with the highest revenue.

## Getting Started
To run this project:
1. Set up a SQL database environment (e.g., MySQL, PostgreSQL, SQLite).
2. Import the **Music Store Database** schema and data into your SQL environment.
3. Use the SQL queries provided in this repository to execute the analysis.

### Prerequisites
- SQL database installed on your system.
- Basic understanding of SQL.

---

## Database Structure
The Music Store database contains the following key tables:
- **employee**: Details of employees, including job titles.
- **invoice**: Customer billing details and transactions.
- **customer**: Information about customers.
- **track**: Metadata about individual tracks.
- **album**: Collection of tracks grouped as albums.
- **artist**: Information about artists and bands.
- **genre**: Music genre details.

## Question Sets

### **Question Set 1 - Easy**
1. Identify the senior-most employee based on job title.
2. Find countries with the highest number of invoices.
3. Retrieve the top 3 highest invoice totals.
4. Determine the city with the highest total revenue for a promotional event.
5. Identify the best customer based on total spending.

### **Question Set 2 - Moderate**
1. List emails and names of customers who listen to **Rock Music**, sorted alphabetically.
2. Identify the top 10 artists with the most **Rock Music** tracks.
3. Retrieve track names and durations for songs longer than the average track length.

### **Question Set 3 - Advanced**
1. Calculate the total amount spent by each customer on specific artists.
2. Determine the most popular music genre in each country.
3. Identify the top customer by spending in each country, including ties.
